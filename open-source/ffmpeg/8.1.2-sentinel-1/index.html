Verify the package

After downloading the files, run the following command in their directory on macOS:

shasum -a 256 -c SHA256SUMS

The command should report OK for every listed file. The checksum file covers the source and build materials; it intentionally does not include this HTML page or itself.

Rebuild notes

The script targets macOS 14.0 or later and builds arm64 and x86_64 slices with Xcode's clang and macOS SDK. It combines the slices into universal helper executables. Networking, shared libraries, device capture, autodetection, and unneeded components are disabled. The build enables only a narrow set of demuxers, video decoders, parsers, the scale filter, image2 output, and the file and pipe protocols.

See README.txt for the exact command sequence. Paths and the SDK patch version naturally differ between Macs; the configuration selections and reported license should match the supplied records.
