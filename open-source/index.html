FFmpeg 8.1.2

Sentinel Sweep includes separately signed ffmpeg and ffprobe command-line programs from the FFmpeg project. The app launches these helpers as separate local processes for supported video-frame extraction and metadata inspection. The Sentinel Sweep application executable is not linked against FFmpeg libraries.

The helpers were built from unmodified upstream FFmpeg 8.1.2 source and are distributed under the GNU Lesser General Public License, version 2.1 or later. The build does not enable FFmpeg's GPL, nonfree, version-3-only, or external third-party codec-library options. It builds static FFmpeg libraries into the separate FFmpeg executables, enables only the required decoders and tools, disables network support, and enables only the file and pipe protocols.

FFmpeg is a trademark of Fabrice Bellard, originator of the FFmpeg project. The FFmpeg project provides additional legal information.

Third-party filename-signal lists

Sentinel Sweep bundles two generated lexicons used only for local filename scoring:

  • public-profanity.lexicon contains 300 filtered English terms derived from Google Profanity Words.
  • public-adult-hosts.lexicon contains 38,547 adult-domain stems derived from source lists maintained in the StevenBlack/hosts porn extension.

The generation process filters and normalizes the source material into Sentinel Sweep's category|weight|term format. For domain sources, it extracts adult-domain stems of at least seven characters, removes common prefixes, suffixes, and generic terms, excludes snuff and gore sources, combines the remaining terms, and removes duplicates.
